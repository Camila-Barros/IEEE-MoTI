## Description

This repository contains the implementation and experimental setup used in the MoTI architecture, proposed for enabling secure and interoperable communication among Industrial IoT (IIoT) devices.

The solution integrates MQTT communication with mutual TLS authentication and decentralized storage using IPFS, enabling traceability, data integrity, and cross-organizational interoperability.

---

## Repository Structure

- `publish_to_mosquitto.py` → MQTT publisher (IoT device simulator)  
- `subscribe_and_send_to_thingspeak.py` → subscriber for cloud integration  
- `mqtt_to_ipfs.py` → subscriber responsible for IPFS storage  
- `/certs` → TLS certificates (example structure)  
- `/data` → experimental datasets (if available)  

---

## Requirements

- Python 3.x  
- paho-mqtt  
- ipfshttpclient  
- Mosquitto MQTT Broker (with TLS/mTLS enabled)  
- OpenSSL (for certificate generation)  
- IPFS node (local or remote)

---

## How to Reproduce the Results

1. Configure the MQTT broker with TLS and client authentication  
2. Generate and configure certificates using OpenSSL  
3. Configure the IPFS node (local or remote)  
4. Run the publisher script to simulate IoT data transmission  
5. Run the subscriber script to receive messages and store them in IPFS  
6. Collect RTT logs generated during execution  
7. Perform statistical analysis using the collected dataset  

---

## Dataset

The experimental dataset consists of RTT measurements for three QoS levels (0, 1, and 2), with 500 messages per level.

If the dataset is not included, it can be generated by executing the provided scripts under the described configuration.

---

## Notes

- Certificates and private keys are not included for security reasons  
- Network conditions may influence RTT measurements  
- The system supports both local and remote IPFS nodes
